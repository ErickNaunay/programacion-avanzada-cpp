# PSets

Aquí van tus entregas de PSet, una carpeta por PSet: `pset-01/`, `pset-02/`, etc. Cada PSet se agrega a este repositorio (con su enunciado y su `README.md`) cuando se asigna en el cronograma del curso.

PSets 1-4 son sets de práctica progresiva: 10-15 ejercicios de código sobre los temas vistos hasta ese punto del curso, para consolidar los conceptos practicándolos. PSet 5 es distinto: el proyecto final, un proyecto integrador que reúne los temas del semestre en un solo sistema, sin sesiones dedicadas.
