# Semana 1, Sesión 1: Diagnóstico de prerrequisitos

**Lectura previa de esta sesión:** ["Who uses C++?"](https://snyk.io/blog/who-uses-cpp/), Snyk.

## Antes de empezar

Verifica que tu ambiente de desarrollo compile correctamente siguiendo el `README.md` de la raíz del repositorio. Una vez confirmado, entra a esta carpeta:

```
cd semanas/semana-01-sesion-01
```

## Los tres ejercicios

Resuélvelos en orden.

1. **`ejercicio1_control_flujo.cpp`**: escribir una función que determine si un número es primo, usando un ciclo.
2. **`ejercicio2_arreglos.cpp`**: calcular el mínimo, el máximo y el promedio de un arreglo.
3. **`ejercicio3_funciones.cpp`**: refactorizar dos bloques de código duplicado en una sola función con parámetros.

Compila y ejecuta cada uno así (los binarios se generan en `bin/`, que no se sube al repositorio):

```
g++ -std=c++20 -Wall -Wextra -g ejercicio1_control_flujo.cpp -o bin/ejercicio1
./bin/ejercicio1
```
